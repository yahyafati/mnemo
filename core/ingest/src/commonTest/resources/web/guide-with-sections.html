Setting up a build

This guide takes a project from an empty folder to a build that runs on every change, in three short parts.

Install the tools

Install the compiler and the build tool, then check that both start from a terminal. If the version command prints a number, you are ready.

Write the script

Create a file called build.sh in the project folder, with the commands below, and make it executable.

# compile the sources
cc -o app main.c

# run the tests
./app --test

The lines that start with a hash are comments, not headings, and the script ignores them.

Options

Pass a flag to change the output name; the default is the name of the folder the script is in.

Run it on every change

Ask the build tool to watch the folder, and it runs the script again whenever a source file is saved.
