Coroutines basics

A coroutine is an instance of a suspendable computation. Start one with launch:

fun main() = runBlocking {
    launch {
        delay(1000L)

        println("World!")
    }
    println("Hello")
}

Things to remember:

  • Structured concurrency
    • A parent waits for its children
    • A failed child cancels its parent
  • Dispatchers
    1. Dispatchers.Default
    2. Dispatchers.IO
