Mnemo

Spaced-repetition flashcards that keep everything on your device. Free, no account, with optional AI.

Mnemo is a modern take on Anki: FSRS-6 scheduling, cloze, type-in and multiple-choice cards, Anki .apkg import and export, and card creation from your notes, PDFs and links through an AI provider you choose. It runs on Android, Windows, macOS and Linux.

Installing, and the warnings you will see

Mnemo is not in an app store, and the Windows and macOS installers are not signed (that costs money a free app does not have yet). So your system warns you the first time. Nothing is wrong with the file: the warning only says that the system has not heard of it. The first section below says how to check that the file is the one that was published.

Android (10 or newer)

  1. Download Mnemo-android.apk on your phone.
  2. Open it. Android asks you to allow installs from your browser or file manager: allow it for this one app (you can turn it off again afterwards).
  3. Play Protect may say it has not seen the app before. Choose More details, then Install anyway.

One APK covers every phone and tablet. Each release is signed with the same key, so a new APK installs over the old one and keeps your decks.

Windows 10 or 11 (64-bit)

  1. Run Mnemo-windows-x64.msi. It installs for your user only, with no administrator prompt.
  2. If Windows says Windows protected your PC, choose More info, then Run anyway.

macOS 12 or newer

  1. Open Mnemo-macos-arm64.dmg (Apple Silicon: M1 and later) or Mnemo-macos-x64.dmg (Intel) and drag Mnemo to Applications. Apple menu › About This Mac says which chip you have.
  2. Open Mnemo. macOS says it cannot check the app for malware. On macOS 14 and older, right-click Mnemo, choose Open, then Open again. On macOS 15 and newer, open System Settings › Privacy & Security, scroll down to the message about Mnemo and choose Open Anyway.

Linux (x86-64)

sudo apt install ./mnemo-amd64.deb       # Debian, Ubuntu, Mint
sudo dnf install ./mnemo-x86_64.rpm      # Fedora, openSUSE
tar xzf Mnemo-linux-x64.tar.gz && Mnemo/bin/Mnemo   # any other: portable

There is no warning, except that your package manager may say the package is unsigned: these files are not in a repository. You need a desktop with X11 or Wayland.

More detail on the desktop (data folders, sound, file types, uninstalling) is in the desktop install guide.

Check your download

Every release has a SHA256SUMS.txt: one line per file with its SHA-256 hash, a fingerprint of the file's exact bytes. If the hash of your download is the one in that line, you have the file the release built, with no corruption on the way. Compare it:

sha256sum Mnemo-android.apk              # Linux
shasum -a 256 Mnemo-macos-arm64.dmg      # macOS (Mnemo-macos-x64.dmg on an Intel Mac)
Get-FileHash Mnemo-windows-x64.msi       # Windows PowerShell

On Linux, sha256sum -c --ignore-missing SHA256SUMS.txt checks every file you downloaded at once. Releases also carry a build attestation, so gh attestation verify <file> --repo yahyafati/mnemo shows which workflow built the file.

Updates

Mnemo never checks for updates itself, so it makes no network request to find out whether there is a new version. Settings › About › Latest release opens the releases page in your browser.

Android, automatically: Obtainium is a free app that watches a GitHub releases page and installs new versions for you.

  1. Install Obtainium, then add Mnemo to Obtainium (or paste {{repo}} into its Add App box).
  2. Each release has two copies of the APK, one with the version in its name and Mnemo-android.apk. If Obtainium asks which one, choose Mnemo-android.apk, or set its Filter APKs by regular expression to ^Mnemo-android\.apk$.

Android, by hand: download the new APK and open it. It installs over the old one and keeps your decks and settings.

Desktop: install the new version over the old one. Your collection is outside the install folder, so it stays.

Before any update you can make a backup in Settings › Data.

What you can trust

  • Free, and it stays free. No account, no subscription, no ads.
  • Your cards stay on your device. No server, no analytics, no crash reporting. The developer receives nothing about you.
  • The internet only when you ask. Mnemo goes online only for an AI provider you set up, and for a link you give to Smart Extract. Everything else works offline.
  • The AI keys are yours. You bring your own provider (OpenAI, OpenRouter, a local Ollama, …). Keys are stored encrypted on your device and are never part of a backup or an export.
  • Open source, GPL-3.0-or-later. The source of each release is the repository at that release's tag (every release also has a Source code download). You can build the same app yourself.
  • A privacy policy that says all of this in full.

Something went wrong?

Mnemo has no crash reporting, so you only hear about problems if you tell us. Please open an issue or write to {{email}}, and say which version you have (Settings › About) and what system you use. Issues are public: do not paste your cards or any API key.
